# Data — Access and Governance Note

Raw dataset files are **not committed** to this repository. They contain commercially sensitive upstream production and evacuation data from OML 18 operations.

## Files Required to Render

Place the following files in this `data/` folder before rendering:

| Filename | Description |
|----------|-------------|
| `daily production report.csv` | Daily actual and budgeted production by station (CC1, CC2, CC3, ALK) — January to May 2026 |
| `evacuation_report.csv` | Daily evacuation capacity and utilization by zone — January to May 2026 |
